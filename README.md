# 🌤️ Simple Weather App

_A live weather display application developed using HTML, CSS, and JavaScript, integrating the OpenWeatherMap API to provide real-time weather information for various regions._

---

## 📌 Overview

The **Simple Weather App** allows users to retrieve current weather data for any specified city. By leveraging the `OpenWeatherMap API`, the application fetches and displays:

- 🌡️ **Temperature**
- 💧 **Humidity**
- 🌬️ **Wind Speed**
- 🌥️ **Weather Conditions**

### ✅ Features

- **Real-Time Data**: Fetches up-to-date weather information.
- **Responsive Design**: Ensures compatibility across various devices.
- **User-Friendly Interface**: Simple and intuitive design for seamless user experience.

## 💂️ Installation & Usage

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/chirag1689/Simple-Weather-App.git
cd Simple-Weather-App
```

### 2️⃣ Obtain an OpenWeatherMap API Key

1. Sign up at [OpenWeatherMap](https://openweathermap.org/api) to get a free API key.
2. Replace `'YOUR_API_KEY_HERE'` in the `main.js` file with your actual API key.

### 3️⃣ Run the Application

- Open `index.html` in your preferred web browser.
